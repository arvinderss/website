02 Setup

Getting both tools running

Install once, then check versions before you ever debug anything else.

Termux specifics. Run termux-setup-storage once and work through ~/storage/shared rather than raw /sdcard paths — Android's scoped storage breaks direct writes on most modern devices. The Termux ffmpeg build is software-only, so plan for CPU-bound encodes and thermal throttling.
